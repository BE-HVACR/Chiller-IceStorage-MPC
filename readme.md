# Modelica Building HVAC-TES Testbed and MPC control Framework

## Modelica model is validated with NIST Chiller-Ice Storage experimental data
The demo HVAC-TES Modelica model is located at `VirtualTestbed.NISTChillerTestbed.DemandFlexibilityInvestigation.FakeSystem.SystemForMPC_1bInput_modeSignal`

## MPC framework is developed in Python and implemented through co-simulation with the FMU compiled from Modelica model
The demo MPC controller is located at `mpc\differentiable_neural_network\3_mpc\manage_mpc_scenarios.py`
